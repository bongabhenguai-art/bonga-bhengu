## Unified operating model
Discovery → evidence verification → business digital twin → diagnosis → opportunity → business/brand/marketing plan → hook → offer → lead → qualification → Closer → approval → Studio/Builder/Execution → real measurement → learning → next opportunity.

Daily owner workflow: Business Morning dashboard → AI Coach's evidence-based priorities → authorized actions → performance review → AI Mentor's 30/60/90-day recommendations. Missing business data must show **not connected / unknown**, not fabricated revenue or health indicators.

## Intelligence and evidence contracts
- DeepSearch/FBL: business name and context → candidate identities → source URL/timestamp/confidence → accepted evidence or explicit unknown/not-assessed state.
- Business Digital Twin: tenant-owned profile, digital presence, offers, market, customers, operations, strategies, actions and measurement; update only from authorized, provenance-bearing data.
- Visibility: customer journey QUESTION → SEARCH → DISCOVERY → COMPARISON → TRUST → CONTACT → PURCHASE; report breakpoints, not just a vanity score.
- SEO/demand: customer problem → intent → content → proof → offer → action.
- Brand intelligence: recognition, differentiation, consistency, proof, trust; scoring requires reproducible inputs.
- Business plan and opportunity engine: problem → evidence → impact → proposed repair → measurable expected outcome.

## CIA / Vault / Universal Connection Wizard
One existing connector registry, not separate per-agent vaults. Track discovered → available → configured → authorization required → authorized → verifying/syncing → ready, with explicit failure/stale/disconnected states. Official OAuth/provider permissions and encrypted server-side credentials only. A displayed platform card is **not** a connected account.

## Lead, package and execution contracts
- Lead: source, need, consent, qualification, opportunity, proposed package, history and ownership.
- Personalized offer: evidence, problem, required work, scope, cost, expected result and limitations.
- Historical Zuxuru package examples **must not change** Bonga's four subscription entitlements or checkout.
- AI may draft, classify, coach and recommend. External actions require owner/admin policy, appropriate authorization, real integration and audit receipt.
- Studio remains inside the existing Creative Studio module and consumes shared context rather than duplicating customer data.
