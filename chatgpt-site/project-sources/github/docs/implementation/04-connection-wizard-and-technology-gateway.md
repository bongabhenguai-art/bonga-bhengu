# 04 — Connection Wizard and Technology Gateway

Customer chooses a supported service -> understands access scopes -> authorizes through official provider mechanism -> verified callback -> vault-backed scoped credentials -> connection health check -> controlled AI access -> revocation.

Technology registry records repository, version, licence, security checks, dependencies, permissions, costs, resource needs, test evidence and rollback.

Potential connectors: Google Business Profile, YouTube, Drive, Facebook, Instagram, TikTok, GitHub, website hosts, WhatsApp through supported official integrations, AI providers and authorized media services.

MCP connects approved tools/resources. A2A can coordinate compatible external agents. Internal existing AI employees must reuse the same central orchestrator.
Connection statuses must distinguish available, configured, authorized, unavailable and failed. Never simulate successful OAuth.
Current creative-studio/connections.py is development-only and reports configuration_required.
