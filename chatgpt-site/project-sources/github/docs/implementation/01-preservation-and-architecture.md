# 01 — Preservation and Architecture Contract

This contract applies to all Bonga Bhengu App product integrations.

1. Existing Bonga Bhengu App storefront is the single entry point. Do not create a second platform or competing OS.
2. Inspect real files and dependencies before modifying. Keep current Creative Studio routes and source intact.
3. Retain working features and unique capabilities; consolidate duplicates only with migration and tests.
4. Reuse tenant-aware identity, AI employees, tool gateway, storage, billing, permissions, execution ledger and monitoring.
5. Keep Git history; make incremental commits; protect production with tests and rollback.
6. Do not mark mocked, planned or unconfigured features as working.
7. Keep the premium black/gold/blue design language, mobile fit, accessibility and approved animation.
8. Each product (Education Partner OS, Zuxuru, Fashion Lab, Digital Studio, Business Growth) is an integrated workspace in the same app.
9. Data and AI actions are tenant-scoped, auditable, authorized and verifiable.
10. Verify actual storefront source before any production deployment.
