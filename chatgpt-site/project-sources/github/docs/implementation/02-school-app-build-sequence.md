# 02 — School App Build Sequence

The Education Partner OS includes BOTH school management and digital teaching.

Phase 1: Map the existing storefront, auth and tenant schema; establish school/institution roles.
Phase 2: Institution onboarding, campus, academic year, classes, courses, learner records, guardian verification.
Phase 3: Timetables, attendance, assignments, submissions, teacher review, grading and student feedback.
Phase 4: Parent communication, fees/invoices with approved provider, receipts and reconciliation.
Phase 5: AI teaching assistant, lesson planning, tutoring, revision, multilingual voice/text and accessibility.
Phase 6: TVET/university programs, practical assessment, skills portfolios, career and placement support.
Phase 7: Institutional reporting, security review, safeguarding, POPIA data handling, end-to-end tests.
Phase 8: Integrate Education Partner OS as a product in the ONE Bonga Bhengu storefront.

Shared AI employees remain central; school roles get education-specific skills and access scopes.
Do not automate final admissions, discipline, grading or safeguarding decisions without authorized human review.
The existing school specification is docs/education-partner-os-school-app.md.
