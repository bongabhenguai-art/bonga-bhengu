📦 7. INSTALL PLUGIN (TENANT ACTION)
// app/api/plugins/install/route.ts
import { prisma } from "@/lib/db";

export async function POST(req: Request) {
  const { tenantId, pluginId } = await req.json();

  const installed = await prisma.tenantPlugin.create({
    data: {
      tenantId,
      pluginId,
      enabled: true,
    },
  });

  return Response.json(installed);
}
⚙️ 8. PLUGIN LOADER ENGINE (VERY IMPORTANT)

This runs plugins at runtime.

import { prisma } from "./db";

export async function loadTenantPlugins(tenantId: string) {
  return prisma.tenantPlugin.findMany({
    where: {
      tenantId,
      enabled: true,
    },
    include: {
      plugin: true,
    },
  });
}

Important Engineering Principle

One requirement stands out in your request:

"really working system no false connection no false working component"

The only way to achieve that is to only include features after they are fully implemented and tested.

That means:

Do not show a button unless it works.
Do not expose an integration unless credentials are configured and connectivity has been verified.
Use feature flags to hide incomplete modules.
Build automated integration tests for every external service.
Add health checks so the admin dashboard immediately shows if an integration is unavailable.
Gracefully disable features if a dependency is down instead of letting users encounter failures.

That approach produces a platform where every visible capability is backed by working software rather than placeholders.
