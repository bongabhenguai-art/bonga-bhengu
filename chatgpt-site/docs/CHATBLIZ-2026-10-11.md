# Chatbliz guided dashboard assistant

Chatbliz is integrated into the existing /app.html shell, not a separate application. Mobile CSS uses dynamic viewport height, safe-area insets, 16px text input and 44px controls. Android/iPhone support is browser based; physical device and browser rendering QA was unavailable in this environment.

Visible dashboard forms can be completed through one question at a time with available select choices and optional-field skipping. Review & submit transfers answers into the existing form and calls requestSubmit; original handlers own validation, cloud save, errors and confirmation. Chatbliz never claims a request was saved. A changed route or modified draft blocks submission. Existing forms remain under Edit details manually and existing action shortcuts reopen them.

Passwords, hidden inputs, uploads, checkbox approvals, radio groups, colour/range controls and sensitive connection/payment/bank/account forms are excluded. They require their existing controls. Same-origin embedded dashboards can expose eligible visible forms; dashboards without forms offer module navigation, not fabricated execution. Website drafting links to the existing guided/AI website editor.

Chatbliz currently uses deterministic guided questions and dashboard navigation, not unrestricted natural-language AI interpretation. SpeechRecognition is optional and requires browser permission/support; transcript is reviewed before Send. Unsupported browsers offer text. No additional AI subscription or external service was activated.

Verification: existing 48-file test suite passed after build; additional UI test passed for review gating, submission through existing handler and changed draft protection. Core tests check sensitive field exclusions.
