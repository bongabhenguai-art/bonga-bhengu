# Existing live app frontend update

Baseline: live site version 119, source `2c6c2cd9077e0296b0637658bb3b94676d00b3b3`.

The storefront header and first screen now open the existing app directly. Four visible cards link to profile, the visual website editor, Digital Studio and orders. Education and the existing AI assistant remain reachable beside them. The app home has the same workspace shortcuts above the existing storefront; its modules, component IDs, account access and backend are preserved.

The Studio links to the existing repository's improved local camera page, including recording-state controls, keyboard focus and fullscreen. It uses the current device's permission-based browser camera and does not claim a remote streaming or AI generation connection.

The existing site identity, public audience, data bindings, backend, payment configuration and source inputs are preserved. Browser layout and real camera hardware were not verified because the supported browser capability is unavailable in this environment.
